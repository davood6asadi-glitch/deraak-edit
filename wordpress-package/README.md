# راهنمای جامع استقرار و راه‌اندازی سامانه صنعتی دراک (Deraak Industrial)

این راهنما برای راه‌اندازی کامل سامانه کاتالوگ صنعتی دراک روی هاست ایران (`https://add.co.ir`) با اتصال ارجاعی به وب‌سایت اصلی (`https://deraak.com`) تهیه شده است.

---

## ۱. محتویات بسته تحویلی (Deliverables)

1. **`deraak-industrial.zip`:**  
   پوسته اختصاصی، فوق‌العاده سبک، راست‌چین و صنعتی دراک با فونت‌های لوکال وزیرمتن و جت‌برینز مونو، سازگار ۱۰۰٪ با المنتور رایگان و ووکامرس.
2. **`deraak-b2b-engine.zip`:**  
   پلاگین هسته B2B شامل متاباکس‌های مشخصات فنی، تاکسونومی برندها، موتور سبد استعلام استعلام رسمی (RFQ)، ۶ ویجت اختصاصی المنتور، مدیریت PWA و پایگاه داده آفلاین IndexedDB.
3. **`sample-deraak-products.csv`:**  
   فایل استاندارد CSV درون‌ریز ووکامرس حاوی ۸ تجهیز واقعی از کاتالوگ دراک (PR 4116, SI5010, FMR53, CLS13, PR 9106B, PR 5116B, FDU95, FMP54).

---

## ۲. پیش‌نیازهای هاست ایران (cPanel / DirectAdmin)

- **PHP:** نسخه 8.1 یا 8.2 (ماژول‌های `curl`, `json`, `mbstring`, `zip`, `gd` فعال باشند).
- **SSL / HTTPS:** برای عملکرد استاندارد PWA و Service Worker داشتن گواهی SSL الزامی است.
- **افزونه‌های پایه رایگان مخزن وردپرس:**
  - **WooCommerce** (ووکامرس نسخه 8.0 یا بالاتر)
  - **Elementor** (نسخه رایگان المنتور)

---

## ۳. مراحل نصب پوسته و افزونه

### مرحله ۱: نصب ووکامرس و المنتور
1. در پنل ادمین وردپرس به مسیر **افزونه‌ها > افزودن** بروید.
2. افزونه **WooCommerce** را جستجو، نصب و فعال نمایید. (مراحل راه‌اندازی اولیه را رد کرده یا ارز را روی «تومان» قرار دهید).
3. افزونه **Elementor** (نسخه رایگان) را نصب و فعال کنید.

### مرحله ۲: نصب افزونه اختصاصی Deraak B2B Engine
1. به مسیر **افزونه‌ها > افزودن > بارگذاری افزونه** بروید.
2. فایل `deraak-b2b-engine.zip` را انتخاب کرده و روی **نصب** و سپس **فعال‌سازی** کلیک کنید.
3. یک منوی جدید به نام **«تنظیمات دراک»** در منوی مدیریت ظاهر می‌شود.

### مرحله ۳: نصب پوسته Deraak Industrial
1. به مسیر **نمایش > پوسته‌ها > بارگذاری پوسته** بروید.
2. فایل `deraak-industrial.zip` را انتخاب، نصب و فعال نمایید.

---

## ۴. درون‌ریزی محصولات نمونه با ابزار استاندارد ووکامرس (CSV Import)

برای درون‌ریزی ۸ تجهیز واقعی کاتالوگ دراک بدون نیاز به افزونه‌های پولی:
1. در پیشخوان وردپرس به مسیر **محصولات > همه محصولات** بروید.
2. روی دکمه **«شروع درون‌ریزی» (Import)** در بالای صفحه کلیک کنید.
3. فایل `sample-deraak-products.csv` را انتخاب کرده و دکمه **ادامه** را بزنید.
4. در صفحه نگاشت ستون‌ها (Column Mapping)، فیلدها به شرح زیر نگاشت می‌شوند:
   - `SKU` ➔ شناسه محصول (SKU)
   - `Name` ➔ نام محصول
   - `Short description` ➔ توضیحات کوتاه
   - `Description` ➔ توضیحات کامل
   - `Categories` ➔ دسته‌ها
   - `Brands` ➔ برندهای سازنده (`product_brand`)
   - `Images` ➔ تصاویر
   - ستون‌های متادیتا (`Meta: _derak_*`) به طور خودکار به فیلدهای متناظر متصل می‌شوند.
5. دکمه **«اجرای درون‌ریز»** را بزنید. در عرض چند ثانیه تمام تجهیزات با کد فنی و پارامترها وارد ووکامرس می‌شوند.

---

## ۵. چیدمان صفحه اصلی با المنتور رایگان (بدون نیاز به پرو)

1. به مسیر **برگه‌ها > افزودن برگه جدید** بروید.
2. عنوان برگه را **«صفحه اصلی»** بگذارید.
3. در کادر ویژگی‌های برگه (صفحه)، قالب را روی **Elementor Full Width (المنتور تمام عرض)** تنظیم کنید.
4. دکمه **«ویرایش با المنتور»** را بزنید.
5. در پنل سمت راست، دسته جدیدی با نام **«المان‌های صنعتی دراک (Deraak B2B)»** مشاهده می‌کنید. ویجت‌ها را به ترتیب زیر به صفحه اضافه کنید:
   - **جستجوی کدهای فنی دراک** (Deraak Technical Search)
   - **کاشی‌های دسته‌بندی مهندسی** (Deraak Bento Categories)
   - **نوار افقی برندهای صنعتی** (Deraak Brand Scroller)
   - **کاروسل محصولات منتخب دراک** (Deraak Featured Products)
   - **محصولات اخیراً مشاهده شده** (Deraak Recently Viewed)
   - **کارت دسترسی آفلاین و نصب PWA دراک** (Deraak PWA Sync Card)
6. برگه را ذخیره و منتشر کنید.
7. به **تنظیمات > خواندن** بروید و صفحه اصلی را روی برگه جدید قرار دهید.

---

## ۶. راه‌اندازی برگه استعلام قیمت رسمی (RFQ Page)

1. به مسیر **برگه‌ها > افزودن برگه جدید** بروید.
2. عنوان را **«استعلام قیمت»** بگذارید و آدرس نامک (Slug) آن را `inquiry` قرار دهید.
3. کد کوتاه زیر را داخل محتوای برگه قرار دهید:
   ```
   [derak_rfq_basket]
   ```
4. برگه را منتشر کنید. اکنون مهندسان با کلیک روی دکمه‌های (+) در سراسر سایت، تجهیزات را به این برگه افزوده و پیش‌فاکتور چاپی یا متنی واتس‌اپ تولید می‌کنند.

---

## ۷. سازگاری PWA در سرورهای لایت‌اسپید و آپاچی ایران

برای اطمینان از اینکه فایل `sw.js` و `manifest.json` با دامنه روت کار کرده و توسط کش مرورگر فریز نمی‌شوند، کدهای زیر در فایل `.htaccess` هاست شما قرار می‌گیرند:

```apache
# Deraak PWA & Service Worker Rules
<IfModule mod_headers.c>
    <Files "sw.js">
        Header set Service-Worker-Allowed "/"
        Header set Cache-Control "no-cache, no-store, must-revalidate"
        Header set Pragma "no-cache"
        Header set Expires 0
    </Files>
    <Files "manifest.json">
        Header set Content-Type "application/manifest+json; charset=utf-8"
        Header set Cache-Control "public, max-age=3600"
    </Files>
</IfModule>
```

## ۸. چک‌لیست بازرسی و آزمون نهایی (Verification Checklist)

- [x] **تفکیک لینک مقصد از سئو کانونی:** تگ `<link rel="canonical">` دست‌نخورده به آدرس محلی `add.co.ir/product/...` اشاره دارد و دکمه Deraak.com صرفاً یک ارجاع مشخص با `target="_blank"` است.
- [x] **عملکرد کامل بدون Elementor Pro:** قالب‌های `archive-product.php` و `single-product.php` مستقلاً و بدون نیاز به تم‌بیلدر کار می‌کنند.
- [x] **ذخیره‌سازی آفلاین کاتالوگ (IndexedDB):** با باز کردن وب‌سایت و کلیک روی دکمه «همگام‌سازی کاتالوگ آفلاین»، داده‌های متنی تجهیزات در پایگاه داده محلی ذخیره شده و در حالت قطع شبکه قابل رویت هستند.
- [x] **عدم کش شدن اطلاعات حساس:** بخش‌های مدیریتی، تسویه‌حساب و درخواست‌های AJAX هرگز توسط سرویس‌ورکر ذخیره نمی‌شوند.
- [x] **استقلال هاست ایران:** فونت‌های وزیرمتن و جت‌برینز مونو به صورت لوکال WOFF2 از داخل هاست لود شده و هیچ ارتباطی با سرورهای مسدود یا تحریم‌شده ندارند.
